# retrospective/

チュートリアル完了後のふりかえり蓄積場所。

## 使い方

1. `template.md` をコピーして `{{name}}_{{YYYY-MM-DD}}.md` にリネーム
2. 6 つの質問に回答
3. Git にコミット（過去受講者の参考になる）

## ファイル

- `template.md` — 質問テンプレート
- `{{name}}_{{date}}.md` — 各受講者の回答例

## 目的

- 戻り先判定の発生パターンを蓄積し、ファシリの仕掛け改善に使う
- 次の受講者が「先輩はここで詰まった」と参考にする
- `self-review/final-rubric.md` の質問 1〜5 と対応
